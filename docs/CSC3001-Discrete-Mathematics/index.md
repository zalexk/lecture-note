::: tip 阅读顺序建议
LN0 是课程导览；LN1–LN2.2 是「逻辑与集合」一段（命题逻辑 → 一阶逻辑，附一篇 LN2.2 的勘误与补漏）；LN3 起进入证明方法，LN4.1–LN4.2 讲数学归纳法（含强归纳、良序原理与不变量法）；LN5 把归纳的同一套动作搬到「递归」上——先用它建立递推式（Fibonacci、Hanoi、归并排序、Catalan），再用生成函数与特征方程把递推式解成闭式；LN6 用一个具体问题（怎么算 gcd）把前面几件工具一次用满——欧几里得算法是递归，spc 存在与唯一分解用良序原理，水壶问题的不可能性用不变量法，最后落到算术基本定理。LN7 从 LN6 留下的商余定理进入模算术：同余类、逆元、费马与威尔逊、韩信点兵与中国剩余定理，并用十五数码把「不变量法」再用一次；LN8 转向图论：七桥问题、度与握手引理、同构、树、欧拉回路，证明套路仍是「取极值再矛盾」。按这个顺序读最顺。
:::
